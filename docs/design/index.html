PH2D · Foundation pass

Design system + editor hero, ready for review.

First-pass deliverable: the token system, the visual catalog of every widget the editor draws, and the main editor screen on iPad 12.9. Once you sign off on the language, I'll produce the remaining 16 screens and finalize the four themes.
