# B33 — o papel deixou de se repetir a cada 256 pixels

Em cada imagem: esquerda = antes, direita = depois. Uma aguada azul clara (25 %) assentada no dente do papel Cold Press.
Antes, o desenho do papel era um ladrilho de 256 pixels repetido: numa tela 4K, 15 vezes na largura e 8 na altura.
Agora o papel soma duas leituras de tamanhos diferentes (256 e 241 pixels), e o desenho só se repetiria a cada 61 696 pixels.
A textura, o tamanho do grão e a força do dente ficam iguais (média e desvio a menos de 1 % e 10 %); só some a repetição.
Medida: a semelhança do papel consigo mesmo 256 pixels adiante caiu de 1,000 para ~0,46 (ver `autocorrelacao.txt`).
