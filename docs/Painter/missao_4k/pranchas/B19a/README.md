# B19a — recorte sobre base escondida e Shadows/Highlights sobre quase preto

Em cada imagem: esquerda = antes, meio = depois, direita = o que mudou (vermelho). Fundos: branco, blocos de cor, papel Textured.
«recorte_base_escondida»: riscas recortadas a um disco; escondendo o disco, antes as riscas cobriam a tela toda; agora somem com ele.
«recorte_base_opacidade0»: o disco a opacidade 0 continua a ser a forma do recorte: as riscas ficam só dentro do disco (antes, a tela toda).
«sombras_ruido_quase_preto»: um quadrado de ruído quase preto com Shadows 0,5; antes cada grão virava vermelho, verde ou azul vivo; agora clareia em cinza.
«lente_centro_da_tela» (Chromatic Aberration 24/0/−24): a franja agora é a da placa, centrada na tela inteira; as cores da franja trocam de lado (o vermelho vai para fora).
«desfoque_janela_sem_costura» (desfoque 12 sob a pintura em ladrilhos): antes cada ladrilho repintado deixava uma costura na borda; agora some.
Fora destes casos nada muda (camada visível, cor acima de ~8 tons de preto).
