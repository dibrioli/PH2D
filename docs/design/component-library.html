PH2D / Design system

A canvas-first, gesture-first editor for 2D games.

This catalog is the source of truth for every widget the editor draws. Components are composed from a small set of design tokens (color, type, spacing, radius, motion) so any theme — Forge-SDF, Procreate, Sunstone, Blueprint — can take the same UI without changing markup.

Spacing & radius

A 2/4/6/8/12/16/24/32 scale. Touch targets ≥ 44px on iPad; mouse ≥ 24px. Radius is themeable via Tweaks (sharp / default / round).

Segmented & radio

Segmented control for 2–4 mutually-exclusive views (Inspector tabs sub-modes, gizmo modes). Vertical radio for > 4 options or longer labels.

Color swatch

Swatches drop opens a color popover (5 tabs: Wheel / Sliders / Harmony / Value / Palette). The popover spec lives on screen 08-color-picker.

Tabs

Top tabs split a panel into views (Inspector: Transform / Physics / Render / Script / Custom). Underline-only — no bg fill.

Dialog

Modal — used sparingly: Component editor, Build/Export, destructive confirms. Scrim is dimmed canvas, not opaque.

Delete entity “Slime_02”?

Tree / list row anatomy

A single row hosts: chevron · icon · name · metadata pill · trailing controls. Depth indents in 14 px steps. Right-swipe (touch) reveals secondary actions.
