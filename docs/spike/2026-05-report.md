## Aprendizados (vide ADR-0019 §"Aprendizados não previstos")

1. Bytecode size threshold falho em premissa para Luau.
2. Luau iteration ~60× Rust (não 5×) — confirma divisão arquitetural.
3. bevy_ecs 0.18 mudou nomes de observers (LLM friction medida).
4. `query::<Entity>()` retorna entities internas implícitas — sempre armazenar IDs explícitos quando precisar despawn conjunto.
5. GC do Luau é 200× mais eficiente que threshold — não é gargalo.
6. WASM marshalling é 5× abaixo de 1µs — bridge Luau↔WASM trivial.
