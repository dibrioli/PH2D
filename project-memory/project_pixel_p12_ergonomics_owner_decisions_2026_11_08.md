Dono 08/11 («faça conforme sugere»), P12 — Ergonomia do Pixel Art (plano `docs/PixelArt/P12_plano.md` §9):
1. F2 = renomear camada (como no app); o laço perde a tecla.
2. Run Command = paleta global `Ctrl+K` com os comandos do Pixel + `Ctrl+Space` no Pixel.
3. Atalhos editáveis só no Pixel agora (janela Keyboard Shortcuts); tabela como dados para o app depois.
4. Recuperação do PROJETO inteiro (2 min se mudou; Restore/Discard ao reabrir).
5. User data = cor + texto + tabela name=value editável na tela, em sprite/camada/cel/tag/tileset; `.ase` ida e volta.
6. Grade/xadrez/onion por documento + «Set as Defaults».
7. ⛔ «cuide de não criar conflitos entre atalhos, pois o app tem múltiplos módulos usando múltiplos atalhos».

**Why:** o dono usa vários módulos; uma tecla do Pixel que rouba uma global do app quebra o hábito dele noutro lado.
**How to apply:** tecla do Pixel ≠ tecla global do app salvo passagens declaradas; gate por censo; a janela de atalhos recusa tecla global e diz de quem é. Exceções fixas: balde P, Gradient Shift+P, G = grade, Slice Shift+C ([[project_pixel_slices_owner_decisions_2026_11_07]]).
