O que cada coisa É

Estilo de cor = uma cor com nome, guardada no projeto (abre com o projeto, em qualquer máquina).
⠿ = a lista de estilos; a mesma lista no Fill e no Stroke.
Nome no lugar do código = esta camada está ligada a um estilo.
Corrente partida = soltar do estilo (a cor fica).
Editar um estilo = todas as camadas ligadas mudam juntas.
Apagar = as camadas ficam com a cor, só deixam de estar ligadas.

Pergunta ao dono: ligado como o Figma (editar o estilo muda todas as camadas) — ou só uma paleta (escolher copia a cor e acabou)?
