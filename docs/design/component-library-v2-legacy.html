PH2D — Component Library & Screen Mockups

0. About this file

Esta página é a fonte de verdade visual do editor PH2D. Adapta a linguagem do sdf3d-studio (a app de referência v0.1, em React/TypeScript com WebGL2) para o nosso contexto: motor 2D em Rust+Vello, mesmo design system de tokens / glass surfaces / multi-theme.

Tudo que for implementado em Vello deve corresponder ao que está aqui. Itera-se este HTML primeiro, depois implementa-se em Rust. Os 4 themes do switcher (canto superior direito) cobrem os modos canônicos: Forge SDF (default, magenta dark), Procreate (cyan dark), Sunstone (warm light), Blueprint (CAD light com sidebar fixa).

7. User flows

  1. Create + Brush stroke: abre projeto → Brush selected by default → ajusta Size slider (drag thumb ou type expression no input) → click+drag no canvas → stroke aparece com size/opacity/flow corrente.
  2. Switch tool via LeftSidebar: click no chip M (Move) → palette atualiza active → Float panel atual fade out → Move panel fade in.
  3. Color pick via Color tool: click chip C (ou key C) → cursor vira eyedropper → click no sprite → color picker modal abre com cor sampleada (HSV wheel + hex) → Apply → BrushTool.color_rgba update.
  4. Marquee select + transform: click S (Selection) → drag rect no canvas → marquee aparece → release → selection criada → switch M → drag selection → Lock Axis = X garante movimento horizontal.
  5. Zen mode: Tab → todas as glass surfaces fade out (TopBar, LeftSidebar, BottomHUD, Float panels) com transition 200ms → só canvas + sprites visíveis → Tab again → chrome volta.
  6. Theme switch: click Settings (TopBar) → dropdown Theme → escolhe Sunstone → todos os tokens re-resolve → smooth transition 250ms.
  7. Float panel reposition: grab pill no topo do panel → drag → panel segue cursor → release → posição persistida per-tool (sdf3d ref: position memory por toolId).
  8. Layer flow: click chip L → Layer panel aparece (right side) → click "+" → new layer → drag layer no panel pra reordenar → click eye icon pra hide/show.
