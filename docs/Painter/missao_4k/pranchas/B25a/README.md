# B25a — o canto do pincel de ponta reta girado

Em cada imagem: esquerda = antes, meio = depois, direita = o que mudou (vermelho = mudou). Embaixo, a lupa 4×.
A pincelada: pincel de ponta reta (quadrado) girado 45°, traço em onda, sobre branco, blocos de cor e papel Textured com relevo.
Antes, quando o app dividia o trabalho entre os núcleos, o canto do quadrado podia sair cortado reto numa linha que dependia de quantos núcleos trabalharam (visto num teste: 270 pontos).
Nestas seis pinceladas nada muda (coluna da direita toda branca, 0 pontos em 1080p e 4K, com 2, 7, 32 núcleos e os da máquina): o corte só aparecia em casos raros.
Depois: o mesmo traço dá sempre a mesma imagem, com qualquer número de núcleos e qualquer velocidade do mouse.
