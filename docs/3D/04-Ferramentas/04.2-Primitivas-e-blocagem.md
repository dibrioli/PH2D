# Primitivas paramétricas e blocagem

> Exigência do Enio: *"um forte conjunto de primitivas customizáveis para criar qualquer tipo de Bloco
> pré escultura"* e *"ferramentas facilitadoras como ZSphere"*.

## A lei das primitivas: ela continua viva

Modelo do **Nomad** (e o certo): uma primitiva **permanece paramétrica** — com seus sliders vivos e
editáveis — até o artista mandar **Converter**. Antes disso ela pode ser combinada com outras por
**booleana ao vivo**, e tudo continua editável.

```
[Cilindro r=0.3 h=2] ─┐
                      ├─ união suave (k=0.1) ──► pré-visualização ao vivo
[Esfera r=0.5] ───────┘                          [Converter] → malha esculpível
```

Isso é possível porque a avaliação passa pelo **campo** ([[02.1-Representacao-malha-primaria]]): união,
subtração e interseção de SDFs são uma linha cada, e o `smin` dá o filete de solda que faz a blocagem
parecer barro em vez de Lego.

## O conjunto

### Sólidos básicos (todos com segmentação, bisel e arredondamento)

| Primitiva | Parâmetros |
|---|---|
| **Box** | largura · altura · profundidade · segmentos XYZ · arredondamento · bisel |
| **Sphere** | raio · tipo (UV / icosaédrica / cubo-esfera) · segmentos |
| **Cylinder** | raio topo · raio base · altura · segmentos · tampas · torção |
| **Cone** | = cilindro com raio topo 0 |
| **Torus** | raio maior · raio menor · arco · segmentos · seção (círculo/quadrado) |
| **Capsule** | raio · altura |
| **Plane / Grid** | largura · altura · subdivisões |
| **Disc** | raio · segmentos · furo interno |
| **Prisma N-gonal** | lados · raio · altura · torção |

### O curinga: **Superelipsóide**

Dois expoentes (`n1`, `n2`) varrem um contínuo que contém **cubo ↔ esfera ↔ octaedro ↔ cilindro
arredondado** e todos os intermediários:

```
|x/a|^n1 + |y/b|^n1 + |z/c|^n2 = 1
```

> **Esta é a resposta ao "qualquer tipo de bloco".** Com escala não-uniforme e arredondamento, uma
> única primitiva cobre a maioria dos volumes de blocagem que um artista desenha à mão.

### Geradores por perfil (o que cobre o resto)

| Ferramenta | Entrada | Saída |
|---|---|---|
| **Lathe / Revolve** | curva de perfil 2D | sólido de revolução (taças, torsos, colunas) |
| **Extrude** | perfil 2D + caminho | sólido extrudado com torção e escala ao longo do caminho |
| **Tube / Curve** | curva 3D + perfil de raio | tubo (galhos, cabelo, cordas, chifres) |
| **Screw / Helix** | perfil + passo + voltas | roscas, molas, conchas |
| **Gear** | dentes · módulo · profundidade | engrenagens |

### Agrupadores

- **Metaballs** — conjunto de esferas com fusão; o antepassado direto do Skeleton.
- **Booleana ao vivo** — união / subtração / interseção, com `smin` opcional (fusão suave).

> **A combinação `Superelipsóide + Lathe + Extrude + Tube + Booleana` cobre, na prática, todo bloco
> pré-escultura.** Não é uma afirmação de fé: é o conjunto que o Nomad e o Plasticity oferecem, com o
> superelipsóide acrescentado porque ele sozinho substitui meia dúzia de presets.

## Skeleton — o ZSphere, sem o custo do ZSphere

### O que o ZBrush faz

Um esqueleto de esferas ligadas; o **Adaptive Skin** gera uma malha *"cobrindo a superfície resultante
da fusão de todas as ZSpheres"*. Matematicamente, é uma **superfície implícita sobre um esqueleto** —
convolução de um núcleo ao longo das linhas do esqueleto.

### O que fazemos

Exatamente isso, e o código é curto porque a maquinaria SDF já existe para o remesh:

```
esfera i        → sdSphere(p, c_i, r_i)
ligação i→j     → sdRoundCone(p, c_i, r_i, c_j, r_j)      // cápsula de raios diferentes
esqueleto todo  → smin_k( todas as peças )                 // k = slider "Fusão"
malha           → surface nets sobre o campo → [[04.3-Topologia|remesh]]
```

**Umas 200 linhas**, dado que `sdRoundCone`, `smin` e o extrator já estarão escritos.

### O gesto (a parte que decide se é usável)

| Ação | Resultado |
|---|---|
| clicar numa esfera | cria **esfera filha** ligada a ela |
| arrastar | move a esfera; a pele acompanha ao vivo |
| roda / pinça | muda o raio |
| arrastar no meio de uma ligação | insere esfera intermediária |
| `Del` | remove a esfera e re-liga os filhos ao pai |
| simetria | esferas espelhadas nascem e morrem em par |

- **Pré-visualização ao vivo** em resolução baixa; **Converter** extrai na resolução escolhida.
- O esqueleto **continua existindo** depois de converter (não-destrutivo): dá para voltar, mexer numa
  esfera e re-converter — o que o ZBrush faz e é metade do valor da ferramenta.
- ⚠️ **Bônus grátis:** um esqueleto de esferas ligadas é, literalmente, um **rig**. A wave de pose
  ([[06.1-Waves-riscos-e-alvos]]) usa o mesmo dado para deformar a malha por warp de domínio.

## Por que isto satisfaz "mais fácil que o ZBrush"

O artista nunca vê a palavra *implícita*, *campo*, *isosuperfície* ou *topologia*. Ele vê:

> **bolas que ele arrasta, e barro que aparece entre elas.**
