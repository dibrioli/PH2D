# Objects & Components — o que é objecto, o que é componente

Linha `line/ObjectsAndComponents` (aberta 07/10). Define o que aparece na **Hierarchy** (objecto),
o que aparece no **Inspector** (componente) e o que é **conteúdo** de um objecto, e põe no lugar o
que hoje está solto (Timeline, Motion, física, mixer).

- [01 — O que é objecto, o que é componente](01_objeto_e_componente.md): estado medido, oráculo
  Godot, as leis, a tabela de tudo, a Timeline, as fases e as escolhas do dono.
- `ferramentas/`: o oráculo Godot (`godot_taxonomia.sh`) e a fixture que ele gravou.
- Assenta sobre a [spec/06](../UI_New_and_Simple/spec/06_tipos_e_modos_de_objeto.md) (tipos e modos).
