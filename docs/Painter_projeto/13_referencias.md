## 13.8 Hard Rules referenciadas no spec

Lista completa em [`SKILL_Stack §9`](../../SKILL_Stack_PH2D_Definitiva.md). As que governam o Painter:

- **HR-1** — Core platform-agnostic
- **HR-3** — Zero-alloc no hot path (stamp pipeline)
- **HR-4** — Frame budget (3.5ms Render sub-budget)
- **HR-5** — Determinismo opt-in (Painter em PresentWorld)
- **HR-6** — Asset = blake3 (brushes, strokes, layers)
- **HR-7** — Editor é a engine (feature `editor`)
- **HR-10** — APIs Luau = MCP (Brush Studio expostos)
- **HR-11** — Mutações destrutivas exigem token (painter_clear_canvas etc.)
- **HR-12** — A11y obrigatória (todo widget Painter emite Node)
- **HR-13** — MemoryBudget declarado (Painter Plugin::init)
- **HR-14** — Save format versionado (.ph2d-painter, .ph2d-brush)
- **HR-15** — Strings via i18n (Fluent)
- **HR-16** — Storage lateral serializável (brush params, color state)
- **HR-18** — LOC caps em shells (Painter respeita ≤600 LOC/arquivo)
