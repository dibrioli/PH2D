# B49 — o pó do papel (Pastel, Chalk, Crayon)

1. Antes, ao encostar a caneta, o app borrava a camada inteira para fazer o "pó" do giz; agora só borra os pedaços de 256 px onde o traço passa.
2. Em 4K, encostar a caneta com estes pincéis caiu de 6,65 para 2,62 milésimos.
3. Cada imagem mostra antes (esquerda) e depois (direita) nos 3 fundos: branco, blocos de cor e papel com relevo, em 1080p e 4K.
4. A diferença é invisível: em 1080p nenhum ponto muda; em 4K, um ponto muda 1 nível de 255.
5. O formato do traço, a cor e o papel ficam iguais.
