Para o novo Painter (host de Layers+Efeitos, [[project-painting-removed-layers-effects-kept]] / ADR-0099), o Enio pediu (2026-06-20) um "port idêntico do Blender Texture Painter". Baixei o recorte curado do subsistema de paint do Blender em **`reference/blender-texture-paint/`** (42 arquivos, ~34.4k LOC): Blender 5.2 @ commit `000fc5038a8d58975e3dae4b45badb28044c4583`, via partial+sparse clone do mirror `github.com/blender/blender`. Estrutura `source/blender/...` preservada em `blender_src/`; README.md tem manifesto por-arquivo + mapa de port; FETCH.sh reproduz. Scratch do clone: `/Volumes/MAC_EXTERNO/PROJETOS/_blender_scratch` (descartável). **Deixado `untracked` no git de propósito.**

Núcleo: `paint_stroke.cc` (motor de stroke), `mesh/paint_image_2d.cc` (dab 2D), `paint_image_2d_curve_mask.cc` (falloff), `DNA_brush_types.h`/`_enums.h` (schema do brush), `imbuf/intern/rectop.cc` (blend per-pixel), `image_gpu.cc` (dirty-tiles GPU), `mesh/paint_image_proj.cc` (projection 3D — provável fora do escopo da 1ª fase 2D).

**LICENÇA — RESOLVIDO (Enio 2026-06-20): reimplementação CLEAN-ROOM.** Blender = **GPL-2.0-or-later**; PH2D = **proprietário** (`LICENSE.md`). Port literal = obra derivada GPL = proibido. Decisão: portar **algoritmo/comportamento** em Rust idiomático (DIRETIVA §1), reusando blend/compositor GPL-free de [[project-painting-removed-layers-effects-kept]]. Referências GPL/CC-BY-SA ficam **untracked** no git.

**PLANO EXAUSTIVO em `docs/Painter/`** (00_INDEX, 01_arquitetura, 02_plano_fases, 03_algoritmos, blender_ui_reference/ 17 telas). Achado-chave: o brush é **só uma fonte de writes no `canvas_rgba` do layer ativo** — host (layer stack + compositor GPU 22-modos + undo estrutural + Apply) já existe.
