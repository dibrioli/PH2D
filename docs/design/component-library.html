6. User Flows (top 5)

  1. Create + Brush stroke: open project → Brush selected by default → adjust Size slider → click+drag on canvas → stroke appears.
  2. Switch tool via palette: click M chip in CREATE zone → palette updates active state → Move panel replaces Brush panel at bottom.
  3. Color pick via Color tool: press C key (or click C chip) → cursor turns into eyedropper → click on sprite → color modal opens with picked color → Apply → BrushTool.color_rgba updated.
  4. Zen mode: press Tab → all chrome animates out (panel + zones + palette) → only canvas + sprites visible → press Tab again → chrome returns.
  5. Theme flip: press M (currently — bind to a Settings toggle in the future) → Visuals re-resolve from ph2d-tokens → Dark↔Light transition.
