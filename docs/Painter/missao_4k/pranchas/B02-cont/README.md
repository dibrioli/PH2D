# B02.5 — Ctrl+Z além do limite não congela a aguada longe do traço

Em cada imagem: esquerda = antes, meio = depois, direita = o que mudou (vermelho). Uma aguada azul (Wet Flat) a correr em cima, dois traços embaixo, e Ctrl+Z duas vezes, a segunda já além do limite do desfazer vivo; foto 60 quadros depois.
Antes: o desfazer apagava a água da aguada de cima, longe do traço desfeito; ela parava em riscas. Depois: só o traço desfeito some; a aguada de cima continua a espalhar e fica lisa.
Gerada por `prancha_b02_o_undo_alem_do_tecto` (o «antes» é o caminho antigo `sem_casco`, no mesmo processo). O B02.1 (a tinta de um desenho acordar noutro) não tem prancha: não há caminho antigo guardado; o portão `adormecida::documento_tests` prova-o.
