# Pincéis — os verbos e a lei do traço

## A lei do traço (a parte que quase todo mundo erra)

> **O efeito de um traço é função do CAMINHO, nunca de quão fino o motor amostrou o caminho.**

No ZBrush e no Blender, passar o pincel devagar deposita mais que passar rápido pelo mesmo caminho —
porque cada *dab* soma sobre o resultado do anterior. É um **produto sobre a lista de dabs**, e ele
depende da taxa de amostragem do mouse.

O Painter da PH2D pagou esse bug **quatro vezes** em 2D (mordida do arado, cápsula do relevo, campo de
smear, gate de proteção) até formular a cura. Ela vale igual em 3D:

```
pen-down:  base[v] ← positions[v]          // congela a posição inicial (o "pre")
por dab:   accum[v] ← max(accum[v], w)     // ENVELOPE, não `+=`
por frame: positions[v] ← f(base[v], accum[v], verbo)
```

Três propriedades caem disso, e todas são visíveis para o artista:

1. **Independência de espaçamento** — traçar devagar ou rápido dá o mesmo resultado.
2. **Idempotência sob re-stamp** — re-desenhar o mesmo traço não o intensifica; isso é o que permite
   editar parâmetros do traço *depois* dele, olhando o resultado (o "Adjust Last Stroke" do Painter).
3. **Undo trivial** — `base` **é** o estado anterior, e a lista de vértices tocados **é** a janela.

⚠️ **Exceção deliberada:** os verbos de *deslocamento acumulado* (`Move`, `Snake Hook`, `Elastic`)
compõem por natureza — puxar duas vezes puxa mais longe. Eles usam **composição de mapas**
(`disp_novo(p) = v(p) + disp_velho(p − v(p))`), não `max` — que é exatamente o *smear field* que o
Painter já shipou em 2D, uma dimensão acima.

## O kernel, uma vez

Todo verbo é o **mesmo laço**; o que muda é de onde vem o alvo e que sinal passa:

```wgsl
// para cada vértice na consulta da grade (esfera do dab):
let d    = distance(base[v], dab.center);
if (d > dab.radius) { continue; }
let t    = falloff(d / dab.radius);              // tabela compartilhada
let w    = t * dab.strength * dab.pressure * (1.0 - mask[v]);
accum[v] = max(accum[v], w);                     // a lei
```

E depois, num segundo passe, `positions[v] = alvo(verbo) interpolado por accum[v]`.

## Os verbos

### Família DESLOCA AO LONGO DA NORMAL

| Verbo | Alvo | Nota |
|---|---|---|
| **Draw / Standard** | `base + n · depth` | o pão-com-manteiga |
| **Draw Sharp** | idem, falloff `pow4`, sem suavização | contorno duro |
| **Inflate** | `base + n_v · depth` com `n_v` = normal **do vértice** | infla a forma, engorda |
| **Blob** | inflate com deslocamento proporcional ao falloff ao quadrado | bolha |
| **Layer** | `base + n · depth`, **limitado** a `depth` | altura constante, não empilha |

### Família AJUSTA A UM PLANO (as que dão a leitura de "escultura")

O plano é ajustado por **mínimos quadrados sobre a pegada do dab** — e ele é **inclinado**, nunca
horizontal: um ajuste horizontal *cava uma cratera na encosta* em vez de achatá-la. (Lição paga no
Painter 2D, `plane.rs`.)

| Verbo | Alvo | Sinal que passa |
|---|---|---|
| **Flatten** | o plano ajustado | ambos |
| **Fill** | o plano ajustado | só para **cima** |
| **Scrape** | o plano ajustado | só para **baixo** |
| **Clay** | plano + offset positivo | ambos — é *Flatten com Offset*, o barro que se adiciona |
| **Clay Strips** | idem, com dab **quadrado** | a diferença é a forma do dab, não o verbo |
| **Trim Dynamic** | plano do dab, projeção dura | corte de faca |

### Família SUAVIZA E ENRIJECE

| Verbo | Alvo |
|---|---|
| **Smooth** | laplaciano da vizinhança (ou HC-Laplacian, que encolhe menos) |
| **Sharpen** | o mesmo, com o sinal trocado |
| **Pinch** | move os vértices **para dentro**, na direção do centro do dab, tangencialmente |
| **Magnify** | o oposto do Pinch, empurra para fora tangencialmente |
| **Crease** | Pinch + deslocamento negativo — cava um vinco |

### Família MOVE MATÉRIA (composição de mapas, não envelope)

| Verbo | Comportamento |
|---|---|
| **Move / Grab** | translada o miolo do dab pelo delta do cursor |
| **Snake Hook** | Grab que **arrasta** o miolo e estica a malha (pede dyntopo) |
| **Elastic Deform** | deformação elástica com queda suave e longa (Kelvinlets) |
| **Nudge** | move tangencialmente à superfície, na direção do traço |
| **Twist / Rotate** | rotaciona o miolo em torno do eixo da câmera ou da normal |

### Família NÃO MOVE GEOMETRIA

| Verbo | Escreve em |
|---|---|
| **Mask** | `mask[v]` — e toda a família acima o respeita (`1 - mask`) |
| **Paint** | `colors[v]` (cor por vértice) |
| **Material Paint** | rugosidade / metalicidade / SSS por vértice |
| **Simplify** | decimação local (só com dyntopo ligado) |

## Falloffs

Uma **tabela compartilhada**, uma porta só — o Painter já tem exatamente este enum:
`Smooth · Sphere · Sharper (pow4) · Constant · Root · Curva customizada`.

⚠️ A **curva customizada** é editável num widget que a PH2D **já possui** (`ParamWidget::Curve`, o editor
arrastável do `motion-params` / falloff do Painter). Não se constrói um segundo editor de curva.

## Simetria

- espelho por eixo (`X` / `Y` / `Z`), combinável
- **radial** de `N` em torno de um eixo
- espelho **local** (eixo do objeto) × **mundo**
- ⚠️ a simetria é aplicada **na lista de dabs**, num único ponto de estrangulamento — nunca dentro de
  cada verbo. É o que faz um verbo novo herdar simetria de graça (a lição do `stamp_dabs_inner` 2D).

## Alphas / stencils

Uma textura de alpha projetada no frame do dab (`tangente × bitangente × normal`), multiplicando `w`.
Com `rake` opcional: o frame acompanha a direção do traço.

⚠️ **A direção do traço vem dos CENTROS de dabs consecutivos, não de uma média suavizada** — o Painter
mediu 52° de atraso ao usar a média em pincel grande, e o sintoma lido pelo artista foi *"o rake não
gira"*. Erro pago; não repetir.
