# B16c — o véu de umidade (a sombra do papel molhado, cartão Wetness)

`*_pan_*`: vista afastada a 25 %, a câmera andando 1, 2 px. Linha de cima = antes, de baixo = depois; a última coluna pinta de vermelho o que muda entre as vistas.
Antes: afastado, a borda do véu «borbulhava» ao arrastar a vista (a coluna vermelha tem grão). Depois: o véu fica parado no papel (coluna branca).
`*_zoom400_*`: vista aproximada a 400 %, esquerda = antes, direita = depois. Antes o véu aparecia em quadradinhos (escada); depois sai liso.
A 100 % nada muda. O liso do zoom foi simulado aqui (no app quem o faz é a placa de vídeo, com o mesmo filtro).
