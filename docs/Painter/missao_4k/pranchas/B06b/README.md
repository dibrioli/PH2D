# B06b — o Warp em malha leva o relevo junto

Em cada imagem: esquerda = antes, direita = depois. Um traço de Impasto, movido com o Transform e depois dobrado no Warp (o ponto do meio de cima puxado para cima).
Antes: ao entrar no Warp a tinta saltava de volta para trás, e o relevo ficava onde estava — via-se a sombra de um «tubo» vazio e a cor solta por cima.
Depois: a tinta fica onde o box a pôs, e o relevo vai com ela: a luz e a sombra estão no traço. A borda do traço dobrado é tão suave quanto a do Transform normal.
Ainda falta: há uma risca fina vertical a atravessar o traço (uma costura entre pedaços da malha); é o próximo conserto.
